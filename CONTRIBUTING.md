# Contributing to not-your-qa

We welcome contributions from engineers, founders, and agent builders!

## Core Principles
1. **Zero Hallucination Tolerance**: Any verification rule or pattern added must be deterministic and falsifiable.
2. **Speed Over Bloat**: Automated verification must run in under 5 seconds. Never mandate interactive, resource-heavy desktop browser runs.
3. **Founder First**: Keep the mental model simple. Founders are decision makers, not manual QA testers.

## Submitting Pull Requests
1. Fork the repo and create your feature branch: `git checkout -b feat/new-verification-pattern`.
2. Ensure any added markdown guidelines follow clear, battle-tested engineering practices.
3. Open a Pull Request with a clear description of why the pattern was introduced.

## Support & Maintenance Boundaries
This project is an open-source initiative created by [BaseWorks](https://baseworks.in). We review PRs and issues as time permits. We do not offer private debugging or custom testing SLAs for third-party codebases.
